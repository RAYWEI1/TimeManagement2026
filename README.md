# 时间统计本 · Time Ledger

以 PDCA 闭环为主线的个人时间管理 App（单文件移动端 Web App，无后端，数据保存在本机浏览器）。

依据《时间管理 App 软件开发规格说明书（SRS）V1.1》与《时间统计法原表 V4.2（自动填充）》开发。

## 功能

- **计划**：年 / 月目标九宫格（8 维度 + 核心词）、周计划、日清单（待办 + 习惯）、目标级联与目标路径
- **执行**：项目 → 任务拆解、番茄专注（20 / 30 / 自定义分钟、短休息、打断记录、勿扰）
- **检查**：行式时间日志（对齐原表 V4.2：只输入结束时间、2400 结束当天、自动承接开始时间、三级分类级联、备注自动分类词典、24 小时校验）、时间分析（三级汇总 / 月度 / 星期 / 占比 / 趋势）、周复盘
- **调整**：按日时间日志 Journal、按周观察日记、目标感校准提示

## 使用

直接打开 `index.html`，或通过 GitHub Pages 在手机浏览器打开后「添加到主屏幕」。

数据只保存在当前浏览器的 localStorage，请定期在「我的 → 设置」导出 JSON 备份。
